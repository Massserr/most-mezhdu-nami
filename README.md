# Мост между нами

Уютная браузерная социальная стратегия о Берёзовке, двух берегах и людях, которым нужна дорога. Конкурсная редакция 2.0 развивает исходную игру на TypeScript, Phaser 3 и Vite.

## Запустить готовую игру

Нужен бесплатный Node.js **22.13 или новее** и современный браузер. Интернет нужен для первоначального получения Node.js; готовая игра после установки работает локально без сети, CDN, регистрации и платных сервисов.

- **Windows:** распаковать всю папку, открыть `Запустить игру.cmd`.
- **macOS:** открыть `Запустить игру.command`. Если система запрещает запуск скачанного файла, выполнить в терминале `node scripts/server.cjs` из папки игры.
- **Linux:** `sh start-game.sh`.
- Вручную: `node scripts/server.cjs --no-open`, затем `http://127.0.0.1:4173/`.

Не закрывайте терминал во время игры. Остановка: Ctrl+C. Не меняйте адрес с `127.0.0.1` на `localhost`: localStorage привязан к адресу, порту и профилю браузера. Если порт занят другой программой, launcher объяснит причину; чужой процесс не останавливается.

## Разработка и проверки

```sh
npm ci
npm run dev
npm test
npm run build
```

`npm run dev` открывает сервер разработки на `127.0.0.1`; сборка находится в `dist`. Для раздачи готовой сборки: `npm start`. `npm run format` форматирует исходники, `npm run format:check` проверяет стиль. CI проверяет тесты, сборку и форматирование на Node.js 22.

Браузерные проверки: `npm run test:browser`. По умолчанию используется установленный Chrome. Для Chromium Playwright: `npx playwright install chromium` и `PW_CHANNEL=chromium npm run test:browser`. Результаты по умолчанию пишутся в соседнюю папку `work/browser-check`; путь можно изменить через `ARTIFACT_DIR`. Тест использует отдельный профиль браузера и не затрагивает сохранения обычного профиля.

## Правила семи дней

Начальный бюджет: **700**, пополнения нет. Размещение и улучшения должны укладываться в эту сумму. Можно отменить любое последнее строительное действие текущего дня. После перехода история отмены очищается.

| День                | История и условие                                                                                 |
| ------------------- | ------------------------------------------------------------------------------------------------- |
| 1. Первые шаги      | Вернуть Северной слободе проезд к медпункту                                                       |
| 2. Дорога к знаниям | Школьный маршрут из Северной слободы не дольше 32 усл. ед.                                        |
| 3. Помощь рядом     | В дождь путь с Садовой улицы к медпункту не дольше 16                                             |
| 4. Два берега       | После закрытия южного моста обеспечить все связи и два действующих перехода                       |
| 5. Испытание        | Паводок повреждает неукреплённые деревянные мосты; пожарные пути до каждого квартала не дольше 48 |
| 6. Общее дело       | Подвести дорогу к общей мастерской; открыть все её маршруты, путь Ильи не дольше 26               |
| 7. Мост между нами  | В дождь открыть все 24 маршрута, сохранить два моста и среднее время до 29                        |

Прогноз следующего дня всегда доступен заранее. Пропущенное обещание не закрывает прохождение: оставшиеся задачи можно выполнить, итог учитывает последствия. Жители реагируют на текущее состояние своих реальных маршрутов.

| Работа                       |    Цена |
| ---------------------------- | ------: |
| Новая грунтовая дорога       |      18 |
| Асфальтирование грунта       |      24 |
| Новый асфальтовый участок    |      34 |
| Деревянный северный мост     |     140 |
| Каменный центральный мост    |     220 |
| Ремонт дороги / моста        | 16 / 58 |
| Укрепление деревянного моста |      52 |

Мост строится, ремонтируется и укрепляется целиком за одну цену. Ремонт сохраняет класс покрытия и не даёт бесплатного укрепления. Каменный мост устойчив к паводку; укрепление защищает деревянный. В день 7 грунт на участке 18:4 повреждается дождём, асфальт выдерживает.

## Маршруты и оценка

Дома и учреждения соединяются через заданные входы. Можно двигаться только по четырём соседям клетки с дорогой. Вода, деревья и повреждения непроходимы; река пересекается через мосты. Мастерская открывается в день 6: число проверяемых маршрутов увеличивается с 18 до 24.

Используется **алгоритм Дейкстры с двоичной минимальной кучей**. Он подходит для неотрицательных неодинаковых весов покрытий; BFS не учитывал бы разницу времени. Вес грунта: 2 в сухую погоду и 4 в дождь. Асфальт и мост: 1. Стоимость перехода равна полусумме весов соседних клеток. Времена являются игровыми условными единицами.

Предпросмотр использует копию той же карты и то же ядро маршрутов, что и реальная стройка. Он показывает стоимость, изменение доступности, среднего пути и целей. Советник находит актуальную задачу и, для пожарного доступа, самый трудный маршрут. Это объяснимые классические алгоритмы, без LLM и внешних API.

- `A`: доля доступных путей.
- `S`: среднее `max(0, 1 − время/60)` по всем парам; недоступный путь даёт 0.
- `Q`: доля выполненных в срок обещаний.
- Благополучие: `55A + 30S + 15Q`, где для Q учитываются уже открытые задачи.
- Итог: `35A + 20S + 40Q + 5 × остаток/700`, округление до целого.
- Успех: от 65 баллов, 24/24 маршрута и минимум 5 из 7 задач.
- Высший результат: от 85 баллов, успех и все семь обещаний.

Среднее время показывается только по существующим путям, поэтому рядом всегда виден счётчик доступности. Финальная цель требует всех 24 путей и не позволяет улучшать среднее изоляцией неудобных кварталов.

## Управление

Мышь: инструмент → участок → подтверждение. Клик по зданию без инструмента выбирает маршрут. Клавиши 1–5 переключают инструменты; стрелки при фокусе карты выбирают клетку; Enter подтверждает допустимую работу; Esc снимает выбор. Ctrl/Cmd+Z отменяет работу. Колесо и +/− масштабируют карту, правая кнопка с перетаскиванием перемещает обзор, «Вся карта» восстанавливает его. Звуки включаются и регулируются в шапке.

Меню делает основной экран `inert`. Все изменения партии дополнительно проверяют, что игра начата; Tab не может завершить день под меню. При `prefers-reduced-motion` декоративная анимация карты и CSS отключается.

## Сохранения и совместимость

Основной ключ `berezovka-save-v1` сохранён для совместимости с прежним интерфейсом. Формат данных обновлён до версии 2; альтернативный старый ключ тоже читается. Загрузчик проверяет форму карты, симметрию мостов, бюджет, версию, историю и согласованность задач с днём.

Для версии 1 сохраняются день, дороги и доля оставшегося бюджета (`старый остаток × 700/900`). Прошлые цели переоцениваются по сохранённой сети, история отмены очищается из-за изменения цен. Если на месте новой мастерской была дорога, она компенсируется; остальная сеть сохраняется. При переносе показывается объяснение. Неизвестные версии и повреждённые данные не приводят к падению игры; блокировка localStorage сопровождается предупреждением.

## Баланс и архитектура

Сценарии `tests/scenarios.ts` проверяют центральный мост, северный переход с последующей каменной переправой и новый медицинский подъезд. Все три выполняют семь задач. Остатки: 132, 50 и 68 соответственно; каждое прохождение требует 13–14 строительных действий. Старый двухходовый сценарий проваливает пять задач и не проходит условия успеха.

- `src/core/map.ts`, `types.ts`: карта и типы.
- `src/core/scenario.ts`: дни, цены, цели и прогнозы.
- `src/core/routing.ts`: граф, Дейкстра, объяснения маршрутов.
- `src/core/game.ts`: действия, бюджет, цели, события, показатели, оценка.
- `src/core/residents.ts`: оригинальные персонажи, реакции и концовки.
- `src/core/storage.ts`: проверка и миграция сохранений.
- `src/main.ts`, `theme.css`: интерфейс; `render/MapView.ts`: Phaser, карта, масштаб, эффекты.
- `scripts/server.cjs`: локальная раздача готовых файлов.
