# Демонстрация «Мост между нами»

Запись проводится в отдельном профиле браузера, с нуля, через обычные кнопки. Состояние игры не подменяется. Закадровый текст оригинальный; техническая версия озвучки создаётся системным русским голосом Milena. Голос можно заменить командной записью без изменения сценария.

| Сцена | Изображение и действия | Закадровый текст |
| --- | --- | --- |
| 1 | Меню, начало новой истории, асфальт 18:4, завершение первого дня | `narration/01.txt` |
| 2 | Центральный мост 12:9, история Миши и подсвеченный школьный путь | `narration/02.txt` |
| 3 | Дождь; асфальтирование участков 16:10, 16:11, 16:12; выполненная медицинская цель | `narration/03.txt` |
| 4 | Ремонт и укрепление южного моста 12:14; прогноз паводка | `narration/04.txt` |
| 5 | Паводок; улучшение общего подъезда 9:10–9:13; проверка пожарных маршрутов | `narration/05.txt` |
| 6 | Подъезд к мастерской: 8:11 и 7:11; история Ильи, 24 проверяемых маршрута | `narration/06.txt` |
| 7 | Последний дождь, все цели, итоговая оценка, реакции жителей | `narration/07.txt` |

Длительность сцен согласуется с реальной продолжительностью реплик. `scripts/record-demo.ts` сохраняет тайминги и исходную запись WebM. `documentation/mix_demo.py` монтирует семь реальных сцен к длительности озвучки: при задержках тестового компьютера темп видео приводится к темпу реплики, сама речь не ускоряется. Состояние игры не подменяется. Итоговое MP4 должно быть короче 180 секунд и содержать видео и закадровую звуковую дорожку.

Для повторной записи нужны Playwright, Chrome, FFmpeg и подготовленные аудиофайлы. Для технической русской озвучки на macOS: `say -v Milena -r 165 -f documentation/narration/01.txt -o 01.aiff`. Отсутствие такого голоса на другой системе не мешает самой игре; можно записать реплики вручную.
